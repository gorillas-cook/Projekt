# Инструкции для Claude

## Язык общения

- Всегда отвечай на русском языке, независимо от языка запроса.
- Все английские аббревиатуры при первом упоминании в ответе расшифровывай и переводи на русский.
  Формат: `АББРЕВИАТУРА (English Full Name — перевод на русский)`.
  Пример: `API (Application Programming Interface — программный интерфейс приложения)`.
